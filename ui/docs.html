Machine-readable spec: /api/openapi.json

Example

curl -F preset=audio-flac -F file=@song.wav HOST:8080/api/v1/jobs
curl HOST:8080/api/v1/jobs/<id>
curl -OJ HOST:8080/api/v1/jobs/<id>/output

Send the preset (or options JSON) field before the file field.

DELETE on a job that is still probing or running only cancels it (202); its files are removed when it reaches the canceled state, and a second DELETE removes the record.
